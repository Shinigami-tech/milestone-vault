Escrow · AI auditor · NEAR

Pay for a website only when it works.

The client locks the money in a NEAR contract. When the freelancer hands in the site, an AI auditor opens it in a throwaway sandbox and checks it against the agreed criteria. Pass, and the contract pays the freelancer on the spot. The auditor's key can't send money anywhere else, even if the agent is fooled.

      Code decides

      Pass or fail is plain code comparing measured scores with the criteria the client locked in. The language model only writes the note.

      Sandbox measures

      Each audit runs in a fresh, unprivileged container with no keys. Hostile scripts and hidden instructions on the site are recorded as findings.

      NEAR enforces

      The contract pays only the job's freelancer, only that milestone's amount. The auditor holds a function-call key that can call report and nothing else.
